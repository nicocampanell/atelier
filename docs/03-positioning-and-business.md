# Positioning and business

Status: Draft — all claims and pricing ideas need evidence.

## Working positioning hypothesis

For visual researchers and designers who save inspiration across many places, this is a hosted personal reference workspace that helps them save, rediscover, connect, and use what they collected. Its proposed difference is the complete path from a low-friction save to a source-backed connection or creative output. This is a hypothesis, not a verified advantage: Pond already supports capture, search and assistant workflows, and other tools address parts of this journey. Compare real user tasks against existing bookmarks, folders, Pinterest, Pond and manual boards before making differentiation or pricing claims. See [the reference study](09-reference-research.md).
