# Positioning and business

Status: Draft — all claims and pricing ideas need evidence.

## Working positioning hypothesis

For designers and other visual researchers whose inspiration is scattered across platforms and files, Atelier brings their references together in one accessible place so they can find and use them whenever they need them. The intended promise is “Your references, everywhere, together.” This is a positioning hypothesis, not a verified advantage: Pond already supports capture, search and assistant workflows, and other tools address parts of this journey. Compare real user tasks against existing bookmarks, folders, Pinterest, Pond and manual boards before making differentiation or pricing claims. See [the reference study](09-reference-research.md).

## Pitch 1: intended position

**Atelier is a personal, deliberately curated reference library for designers.** It brings together material the user chooses—web pages, screenshots, photographs of books or physical artifacts, and other sources—and makes it easier to retrieve and connect when a project needs it. The initial audience in the pitch is freelance and UX designers working across projects. This is Nico's intended audience, not a validated segment.

The insight is personal: Nico learned to find inspiration in graphic design books, architecture, artifacts, websites and social posts, but lost references across tabs, folders and platforms. The pitch's guiding idea is that creativity comes from connecting influences across contexts. The product should help preserve the user's own taste and agency: the user chooses what to collect and what relationships mean.

**Current direction:** Make references from different sources available together and easy to retrieve. Notes may help some users, but the product should not depend on explaining why an item was saved. A representative task from the original pitch: find a layout in the library that feels like a vintage magazine cover. A project board provides a context in which to compare and connect what was found.

**Positioning to test:** “Your references, everywhere, together.” Atelier is intended for curation and recall, with the user in control of what is collected and surfaced. Pinterest and Cosmos are examples of current alternatives, but claims that their algorithms determine creativity or that Atelier saves a specific amount of time are pitch hypotheses, not established facts. Test them with actual workflows and current products. “Everywhere” is an aspiration; supported sources and device access must be described accurately in any shipped product.

### Prior prototype

An earlier [Atelier prototype README](../../P2P/Proj1/atelier/README.md) describes a separate project at `Documents/P2P/Proj1/atelier`: capture with optional notes, a stable semantic map, natural-language search and inspection. It describes a Next.js client, Hono API, Supabase, Qdrant, Voyage and worker design. Its development adapters use deterministic hash embeddings and fixed OCR, so its local demo does not establish real search quality. This repository currently contains the planning documents, not that prototype; do not assume its implementation has been imported or verified here. The sources are useful context for future decisions, not a mandate to reuse its stack.
